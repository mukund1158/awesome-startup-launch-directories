# Awesome Startup Launch Directories

> A maintained, **DR-ranked** list of startup and product launch directories - where to submit your startup, what each listing costs, and what the backlink is actually worth.

Most "300+ places to launch your startup" lists are link dumps. Half the sites are dead, none of them tell you what a listing costs, and none tell you whether the backlink is worth anything. This one is small on purpose: every entry has been checked, priced, and ranked by **Ahrefs Domain Rating (DR)** - and the ones that weren't worth it are listed too, with the reason.

## What the "Links" column means

This is the number nobody else publishes, and it changes what a listing is worth more than DR does.

When a directory lists your product, its link to you carries a `rel` attribute. If that attribute contains `nofollow`, `ugc`, or `sponsored`, search engines are told not to pass ranking signal along it. **A DR 78 nofollow link passes no more SEO value than a DR 5 one.** You're buying referral traffic and nothing else - which can still be worth it, but you should know that's what you're buying.

| Value | Meaning |
|-------|---------|
| `dofollow` | Every listing CTA sampled was followable. This is the one you want |
| `nofollow` | Every listing CTA sampled was `nofollow`/`ugc`/`sponsored`. SEO value ≈ 0 |
| `mixed (n/m)` | `n` of `m` sampled listings were nofollowed |
| `-` | Couldn't determine it - see the limits below |

### About `mixed`

A high ratio like `6/8` most likely means the directory **nofollows free listings and dofollows paid ones** - a standard way these sites monetise. I have not confirmed that causally, because the audit can't tell which sampled listings were paid. Treat a `mixed` entry as: *the dofollow is probably the thing the money buys.* Verify on a listing in the tier you intend to purchase before paying.

### How it's measured

[`scripts/check-dofollow.mjs`](scripts/check-dofollow.mjs) fetches the directory's homepage, follows up to 8 individual listing pages, finds the "Visit website" style CTA pointing at the listed product, and reads its `rel`. Each verdict stores the exact page it came from in `linkPolicyEvidence`, so you can check any claim here yourself:

```bash
jq -r '.directories[] | select(.linkPolicy) | "\(.name)\t\(.linkPolicy)\t\(.linkPolicyEvidence)"' data/directories.json
```

Re-run it with `node scripts/check-dofollow.mjs` (add `--write` to update the dataset).

### Limits - read these before trusting the column

- **Server-rendered HTML only.** Six entries show `-` because their listings are rendered client-side, so no crawler-visible link exists in the initial HTML. That is itself worth knowing: if the link isn't in the served HTML, its SEO value is questionable regardless of `rel`.
- **It's a sample, not a census.** Up to 8 listings per site. A directory could treat other listings differently.
- **It's a snapshot.** Any of these sites can change `rel` tomorrow, and some do it precisely when a list like this gets popular.
- **Anchors are matched with a regex**, not a real DOM. Unusual markup can be missed.
- **`nofollow` is a directive, not a guarantee** of how any given search engine actually weights the link.

If you verify one by hand and it disagrees with the table, please open a correction issue - that's exactly what the column needs.

## How to use this list

If you're launching on a budget, a reasonable order of operations:

1. **Do the free ones first.** They cost nothing but time, and a couple of them are high DR.
2. **Then buy DR 70+ that are `dofollow`, in ascending price order.** Use the `DR / $` column to break ties. A DR 74 `nofollow` listing and a DR 74 `dofollow` listing cost the same and are not the same product - check the Links column before you pay.
3. **Space submissions out.** A burst of identical listings on the same day looks like what it is. A few per week reads as a normal launch.
4. **Write the listing once, reuse it.** Nearly every directory asks for the same fields: name, URL, one-liner (~60 chars), description (~200 chars), logo, screenshots, category, pricing model. Keep them in a text file.
5. **Track what you submitted.** Approvals take days to weeks and some directories never reply. Fork this repo's JSON into your own private sheet if you want a status column.

### A note on what a listing is actually worth

A DR 74 directory does **not** pass DR 74 of value to you. What you get is one link from a page that is usually many hops from that domain's strongest pages, often alongside hundreds of other listings, and sometimes `nofollow`. Treat these as:

- **Real value:** discovery, first users, social proof, and a plausible referral trickle.
- **Modest value:** a diversified, natural-looking backlink profile early in a domain's life.
- **Not the value:** a direct ranking jump. If a directory promises one, that's marketing.

Prices and DR change. Verify before you pay - see [`data/directories.json`](data/directories.json) for the last refresh date.

## Data

[`data/directories.json`](data/directories.json) is the source of truth and is meant to be consumed programmatically:

```bash
# Every free listing
jq '.directories[] | select(.priceUsd == 0 and .status == "active") | .url' data/directories.json

# DR 70+ under $20, cheapest first
jq -r '[.directories[] | select(.status == "active" and .dr >= 70 and .priceUsd < 20)]
       | sort_by(.priceUsd)[] | "\(.name)\t$\(.priceUsd)\tDR \(.dr)"' data/directories.json
```

| Field | Meaning |
|-------|---------|
| `name` | Directory name |
| `url` | Homepage (`null` if unverified) |
| `priceUsd` | Cost of a standard listing, USD. `0` = free |
| `dr` | Ahrefs Domain Rating at the time of the snapshot, `null` if unmeasured |
| `status` | `active` (recommended) or `skipped` (evaluated and rejected) |
| `notes` | Caveats, free-tier details, or the reason for skipping |

The README tables are generated from that file:

```bash
node scripts/generate.mjs          # rewrite the README tables
node scripts/generate.mjs --check  # CI: fail if the README is stale
```
